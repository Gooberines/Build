Moon Bot is your automated in-game assistant — built to handle tasks, grind, and move like a machine while you sit back.

⚙️ **STEP 1 — PREP YOUR CLIENT**

* Make sure you have **Fabric 1.21.4** installed
* Launch through your client (TLauncher or custom)
* Verify mods folder is working

📦 **STEP 2 — INSTALL MOON BOT**

* Locate your `.minecraft` folder
  → Press `Win + R`
  → Type: `%appdata%\.minecraft`

* Open **mods**

* Drop in the Moon Bot mod file

⚠️ Make sure:

* Correct Minecraft version
* No conflicting mods
* Fabric API installed

* Wait for full load-in
